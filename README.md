# BOYFRIEND — Homepage prototype

A responsive, dark romantic homepage concept for a fictional AI companion website.

## Project structure

```text
boyfriend-website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

1. Download and extract the project ZIP.
2. Open `index.html` in a browser.
3. For a smoother development workflow, open the folder in VS Code and use a local preview extension.

## What's included

- Responsive landing page
- Dark burgundy, charcoal and muted-gold visual identity
- Hero section and abstract silhouette artwork made with CSS
- Feature cards for personality, fictional daily life, memories and face visibility
- How-it-works section
- Privacy-by-design introduction
- Mobile navigation
- Functional prototype CTA message

## Current limitations

This is a frontend homepage prototype. It does not yet include user accounts, a database, AI chat, persistent memory, notifications or character generation. Those require a backend, security design and an AI integration.

## Suggested next development phases

1. Character creation flow (custom or random)
2. Character profile and appearance preferences
3. Backend and secure authentication
4. AI conversation and memory architecture
5. Fictional daily-life simulation
